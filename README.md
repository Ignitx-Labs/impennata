# IMPENNATA

A browser wheelie game by IGNITX Labs. Ride motorbikes and bicycles, pull wheelies, jump ramps, and race, with keyboard or webcam hand/body controls.

**Play:** https://ignitx-labs.github.io/impennata/

Built with [Three.js](https://threejs.org/) and [MediaPipe](https://developers.google.com/mediapipe). All bikes, brands and riders in the game are fictional.

Run locally: serve the folder with any static server, e.g. `python -m http.server`, then open http://localhost:8000.
